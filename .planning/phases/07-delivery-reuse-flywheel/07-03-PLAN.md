# 07-03: S3 成功复用条 CTA

## Objective

success 终态展示复用条：保存为模版 / 设为定时 / 再跑一次；查询 `source_run_id` 是否已有模版。

## Context

- Design Part B1–B2
- Depends on S2 conclusion area
- `listTemplates` + filter `source_run_id`
- `openSaveTemplateWizard` from save-wizard

## Tasks

### Task 1: `#run-reuse-bar` UI

- success: primary「保存为模版」; secondary「设为定时」「再跑一次」
- If template exists for run: show name; primary「设为定时」; secondary「再跑一次」
- partial (mixed success+failed nodes): secondary save only, no schedule
- failed/cancelled: hide reuse bar (or only retry hint)

### Task 2: Actions

- Save → existing wizard with runId/goalId/planId
- Schedule → if has template call `openCreateScheduleModal` (S5 export; stub navigate to schedules+new until S5)
- Rerun → if template: navigate templates run form; else toast「请先保存为模版」or re-open commander with goal (minimal: toast + open template if any)

## Verify
